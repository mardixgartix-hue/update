GitHub Deployment Workflow
Use this process to publish content and image changes safely.
1. Add image files

Upload product images to assets/images/products/ or hero images to assets/images/hero/ in GitHub.

2. Set the image path

In the product or hero editor, use the matching public path, such as /assets/images/products/new-product.jpg.

3. Download the JSON

Open Direct JSON Editor, apply your changes, then use Download JSON to download the updated site-data.json.

4. Commit both files

Replace the root site-data.json in GitHub and commit it together with the image files. The deployed site then loads both automatically.

This admin page prepares and downloads the files. It does not upload or push files to GitHub.
